---
name: manage-personal-context
description: Create, edit or remove personal skills and global agent instructions (AGENTS.md and CLAUDE.md) managed by agent-home.
---

Personal context is managed in the personal repository recorded in the `repo`
field of `~/.agent-home/state.json`. Read that field before editing sources;
do not infer the repository from its name or the current checkout.

Keep that installation clone on `main`, with no uncommitted changes or
unpublished commits, so automatic sync can run. For branch/PR work, use
another clone or worktree of that repository. Do not run `sync` from there:
the installation state belongs to the installation clone.

Installed copies are generated; their sources live in the repository.

Sources are organized into these scopes:

- `common/`: all computers and harnesses.
- `harnesses/<harness>/`: one harness.
- `machines/<computer>/`: one computer.
- `machines/<computer>/harnesses/<harness>/`: one combination.

Global instructions are generated by concatenating the selected scopes'
`FRAGMENT.md` files in that order.

Each skill occupies a `skills/<name>/` directory within a scope, containing
a `SKILL.md` and optional resources. Skill names must be unique across
the selected scopes.

The computer syncs automatically with `origin/main` every 15 minutes.
Once changes reach `origin/main`, sync from the installation clone with
`python3 "<repo>/agent_home.py" sync`
(`py -3 "<repo>/agent_home.py" sync` on Windows), where `<repo>` is the
installation path recorded in the state file.

`origin` points to the personal repository; `upstream`, if configured,
points to the public project.

Project-specific instructions and skills, and plugin-managed skills,
are outside this system.
